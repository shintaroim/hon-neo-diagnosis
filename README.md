## 🚀 プロトタイプの実行方法
`矢野尚美_世界観診断ツール/矢野尚美_世界観診断プロトタイプ.html` または `HON-NEo_全診断プロトタイプ.html` を任意のブラウザ（Chrome, Edge, Safari等）でダブルクリックして開くだけで、実機同様の診断を体験できます。
